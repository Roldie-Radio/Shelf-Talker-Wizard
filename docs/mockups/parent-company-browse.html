Browse by Parent Company

The Bourbon Library's toolbar already counts 66 parent companies across its 279 entries, but today that number is just a stat — there's no way to see the list or drill into one. This mockup proposes a second browse mode alongside the existing bourbon grid: a company view, tiered by how many bourbons each owns so the five conglomerates that account for over a third of the whole library (Beam Suntory, Sazerac, Heaven Hill, Brown-Forman, Diageo) read as obviously more prominent than an independent single-bottle brand, without the other 61 companies getting lost. All the counts and bourbon lists below are the real, current library data.

Design notes

Three tiers, not a treemap

A literal proportional treemap gets unreadable fast with 66 items and company names as long as "Latitude Beverage Co. (Liquor Barn private label)". Instead, companies are bucketed into three fixed tiers by bourbon count — Featured (13+, currently the top 5), Major (5–12), and the rest — each rendered at its own card size and information density. Prominence comes from tier membership, card size, and typographic weight together, not from precisely proportional area the way a treemap would demand.

Featured tier gets a bar too

Each Featured card's mini progress bar is relative to the single largest company (Beam Suntory, 30 entries) — not to 279 total — so the five bars actually differentiate from each other instead of all reading as "nearly empty" against the full library.

Sort: Most bourbons vs. A–Z

Defaults to count descending (matches the "larger companies more prominent" ask), with an alphabetical toggle for someone who already knows the name they're after and doesn't want to hunt through tiers. Search filters by company name only, live-narrowing whichever tiers still have matches.

Drilling in reuses the profile page's own pattern

Clicking a company (any tier) swaps to a detail view with a breadcrumb back, the same grid-→profile→back relationship the existing bourbon grid already has (libraryViewMode in app.js) — this would be a third mode on that same state machine, not a separate screen. Each bourbon row is clickable too, a straight handoff into the real bourbon profile page.

Where "parent company" text comes from today

This is free text per entry (parentCompany on the mash_bills row) rather than its own table, which is why the same real company shows up under slightly different strings in a few places in the actual seed data (e.g. "Diageo" vs. no variants seen yet, but "Sazerac Company" is consistent while a few independents write out a parenthetical like "(independently owned)" as part of the name). Grouping here is a straight string match, so any future company name inconsistency would quietly split what should be one company into two entries — worth normalizing into a real lookup if this ships, not just matched as typed.
