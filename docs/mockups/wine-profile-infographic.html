Wine Profile infographic — a 1–5 dot meter for Fruit / Body / Dry / Acidity / Alcohol

Proposes an optional Wine Profile block for Wine / Spirits Shelf Talkers: five small at-a-glance meters — Fruit, Body, Dry, Acidity, Alcohol — each scored 1–5 with filled dots, the same visual language the app already uses for the Untappd Rating widget on Beer talkers (.card__beer-dot in public/css/styles.css) — just applied across five categories instead of one overall score.

  • Placement: directly under Description, above Ratings/Awards — its own line with a top divider, the same treatment .card__flavor (Nose/Palate/Finish) and .card__pairings (Pairs Well With) already use.
  • Shape: one horizontal strip, 5 equal columns (label over its own row of 5 dots), not 5 stacked full-width rows — a wine talker can already be carrying Ratings, Awards, and Food Pairing chips underneath this, so the strip trades a little column width for a lot of vertical space back.
  • Entry: staff click dots to set each score by hand, same as any other field — plus a Suggest Profile button next to the field that prefills all five from a small varietal keyword table matched against Product Title, the same pattern Suggest Pairings already uses for Food Pairing Suggestions. Suggested values stay fully editable; the status line under the picker tracks whether the current values came from a suggestion or were hand-edited.
  • Gating (not built into this mockup): would sit behind its own Settings → Experimental Features toggle, same as Wine Food Pairings — see wine-pairings-experimental-toggle.html for that switch pattern. This mockup exposes it as a plain Show Wine Profile on this shelf talker checkbox instead, to keep the focus on the block itself.
  • Try the sample wines below to see five genuinely different shapes (a bone-dry, high-alcohol Cabernet reads nothing like a light, off-dry Riesling), or click any dot to hand-edit a score and watch the card update live.
