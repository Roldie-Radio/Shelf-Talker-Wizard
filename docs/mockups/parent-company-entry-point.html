Getting to Parent Companies from the Bourbon Library home screen

This is the real, current Bourbon Library screen — the left icon rail, the header band with search/filter chips/stats, and the bourbon grid — exactly as it looks today, with one addition: the existing "Parent companies" stat in the stats row (today just a number) is now a button. Design notes

Why the stat itself, not a new button

The header band already tells staff "67 Parent companies" (now 66, see the last mockup) every time they open the library — that's already doing half the work of advertising the feature exists. Turning it into a link costs zero new screen space and puts the entry point exactly where curiosity about that number would already be. A separate "Browse by Company" button elsewhere would just duplicate that signal in a second place.

Getting back

The company view keeps the same header band and rail — only #libraryBody swaps out, same as switching between the grid and a bourbon's own profile page today. The existing search field and confidence chips stay visible but inert while browsing companies (they filter bourbons, not companies); the fastest way back to the grid is the rail's own Bourbon Library icon, already just one click away and always visible.
