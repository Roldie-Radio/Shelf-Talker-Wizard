Click-to-Edit in the Full Page Live PreviewConcept

Today, editing a talker you spot on the Full Page preview means finding the matching row in the Queue list below and opening its ⋮ menu. This mockup lets staff click the talker itself, right there on the scaled-down sheet, and jump straight into editing it — useful when you're eyeballing the printed layout and catch something wrong (a stale price, a typo) by how it looks rather than by its title text.

  • Try it: switch to Full Page below, hover any talker to see the edit affordance, then click one (or Tab to it and press Enter) to select it for editing.
  • Clicking a talker here does exactly what the Queue row's existing Edit action already does — fills the form and switches to Current Talker — this just adds a second, more visual way to reach it. No new save/delete behavior.
  • This is a static, self-contained mockup for reviewing the idea — it isn't wired into the real app, the queue, or the print CSS, and nothing here is saved.

How the interaction works

1 Hover — a talker lifts slightly and gets a thin accent ring plus a small ✎ Edit badge in the corner. The ring sits outside the card's own border, so it never changes the card's printed proportions while you're judging the sheet.
2 Click (or Enter/Space on a focused card) — selects that talker for editing: the Edit Talker form on the left fills in, the Live Preview toggle switches to Current Talker so you can see the full-size card you're now editing, and the page scrolls to the top — the same three things startEdit() already does today from the Queue row's ⋮ → Edit menu.
3 Keyboard & screen readers — each talker is a real <button>, so Tab cycles through them in print order (the same order they'll come off the printer) and each announces as “Edit <title>, button.”
4 Scope — this is single-target click-to-edit, not multi-select/bulk actions. Move/Duplicate/Delete stay in the Queue row's ⋮ menu, unchanged.
