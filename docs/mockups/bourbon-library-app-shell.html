Bourbon Library App Shell

✅ Decided: Sidebar Rail

Of the three entry points compared last round, Sidebar Rail is the pick — a persistent icon rail down the left edge of the whole app, with Bourbon Library as one first-class icon alongside the app's existing screen rather than a tab switch or a header button. Manual Entry / Import / Search, the Queue side panel, and History all stay together under one Shelf Talker icon, reached exactly the way each is reached today. Settings keeps its own rail icon rather than nesting inside Shelf Talker — a standing destination for the one screen most likely to get more settings over time, not just a single menu item.

Both new icons are drawn rather than emoji: Shelf Talker is a tiny rendering of an actual printed talker, and Bourbon Library is a Glencairn glass — the shape whiskey gets nosed and tasted from, redrawn as a clean two-tone inline SVG (outlined neck, solid-filled bowl) to match a reference glass shape, in the app's own ink/gold tokens instead of a raster placeholder. The rail's top mark is the real Liquor Outlet Wine Cellars logo now too, not a placeholder "STW" badge. Click between Shelf Talker, Library, and Settings to swap the content pane. Flip Bourbon Shelf Talkers off in Settings, then check the Shelf Talker tab and the Library icon — one changes, the other doesn't.

One thing earlier versions left out entirely: the real app also has a Windows-style menu bar (File / Tools / Advanced / Help, above the app bar) that never appeared in this mockup. File and Tools stay — they're Queue/talker-specific (Open/Save/Find Queue, Beer Talker Info, Wine Pairing Rules), and the Queue itself is persistent app state regardless of which rail icon is active, so this menu bar now spans the full width of the app, above the rail, rather than living inside the Shelf Talker screen. Design notes

Queue and History fold in; Settings keeps its own icon

Queue is already a side panel on the same screen as the form, and History is already a button that opens a dialog — neither is a separate top-level screen today, so neither needed its own rail icon; both stay nested inside Shelf Talker (renamed from an earlier "Build"). Settings gets its own rail icon back rather than folding in too — it's the one screen most likely to grow more settings over time, and staff reaching for it shouldn't have to go through Shelf Talker to get there.

Icons drawn from the product, not picked from an emoji set

Shelf Talker is a tiny rendering of an actual printed talker — white card, dark border, red price block, using the same --ink/--sale-red print colors the real cards use. Library is a Glencairn glass — the nosing glass shape, standing in for "everything we know about what's in the bottle" — redrawn as two stacked SVG paths (a solid-filled bowl/foot path underneath, a stroke-only outline path on top spanning rim to base) so the neck reads as glass and the bowl as contained liquid, without a separate clip-path. Same technique on the rail icon (gold fill on the neutral rail background) and the Library header band's own icon (cream fill so it reads against that icon's gold badge instead of disappearing into it). The rail's brand mark is the real store logo now, not a text placeholder.

Decoupling, now shown where the flag actually lives

The Experimental Features switch sits on its own Settings screen, reached from its own rail icon — flip it off, then switch to Shelf Talker and only the Mash Bill / Nose-Palate-Finish fields react. The Library icon, its content, and its own confidence filters are untouched, because they never read that flag to begin with.

Decided: Advanced & Help → Settings, menu bar goes full-width

Advanced (Export File Settings, View Export File, Server PC) and Help (What's New, Check for Updates, About) are now two new sections on the Settings screen, alongside Experimental Features — open Settings to see them. That leaves File and Tools as the only two menus, and since both operate on the Queue (which persists no matter which rail icon is active, not just while Shelf Talker happens to be open), the bar moved out of the Shelf Talker screen entirely and now spans the full width of the app, above the rail — permanent chrome, not a per-screen element.

Open question this raises: should the Queue panel go full-width too?

The menu bar's File > Save Queue is now reachable from Library or Settings, but the Queue side panel itself still only renders on the Shelf Talker screen — a staff member could save/find the queue from anywhere, but not see it, without switching back. Worth deciding whether that's a real inconsistency (Queue count badge always visible somewhere?) or fine as-is, since Print Now/the actual print flow is still Shelf-Talker-specific either way.

Open questions

  • Queue visibility outside Shelf Talker (see above) — still open.
  • Does "Add a bourbon" belong in the Library itself now (a real add-entry flow, not just the Edit Talker form's "Save this mash bill" checkbox), now that it's meant to stand on its own as a reference?
  • Storage/sync stays exactly as designed for the Mash Bill Library (Server-PC-hosted, every register polls) — this is presentation only, not a new data architecture.
  • Card grid vs. table for Browse: grid reads more "reference app," but a dense table scales better past a few dozen entries. Worth revisiting once real shelf data is seeded in.
