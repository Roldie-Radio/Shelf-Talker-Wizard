Bourbon Profile Pages & Mash Bill Confidence

Today the Mash Bill Library is a flat table of title → grain composition, built to feed the Edit Talker form's recall banner. This mockup proposes a read-focused profile page on top of the same entries — distillery, parent company, tasting notes, and mash bill in one place — so it doubles as a staff reference, not just shelf-talker plumbing. Click a bourbon on the left to open its page.

Because a lot of mash bill data is industry-reported rather than distillery-confirmed (see the seed list compiled earlier), each profile also carries a Mash Bill Confidence section — a scoring system so staff can see at a glance how sure we actually are, instead of every entry looking equally authoritative. It's a staff-only signal: it never prints on the shelf talker itself, only the grain composition does when one is known.

Design notes

How Mash Bill Confidence is scored

Four tiers, ordered by how directly the number traces back to the distillery itself — not a statistical score, just a plain rule for which bucket an entry belongs in:

TierMeterWhat qualifiesHow staff should treat it
Confirmed The distillery currently publishes the exact grain percentages itself (own site, press kit, label filing). Safe to state as fact.
Reported Not published by the distillery, but 2+ independent reputable sources agree within a few points of each other. Good working number — cite as "commonly reported," not distillery-confirmed.
Estimated Only one source, or multiple sources disagree / give a wide range. Treat as a rough range, not a fixed number.
Unknown Nothing found beyond the whiskey category's legal minimum (e.g. ≥51% corn for bourbon). Leave the mash bill blank — don't present a legal minimum as the real recipe.

Profile page = a view, not a new editing surface

Every field shown here (grains, sources, tasting notes) still lives in the existing mash_bills row and is still edited through the Edit Talker form's Mash Bill field or the Manage Mash Bill Library dialog — same Server-PC-hosted sync already built for the library. This page is a read-focused layout on top of that data, the same relationship a product page has to its underlying database row.

The "Other … in the Library" list on the right and the "Edit in Library" button are how a profile page would hand off to that existing editing surface rather than duplicating it.

Schema gap this would need to close

Today's mash_bills table has title, distillery, grains, and one free-text source string. A real version of this page needs new columns: parent company, category/style tag, structured tasting notes (nose/palate/finish, reusing the shape Bourbon Shelf Talkers already put on a talker), and the confidence block itself — tier, a short rationale, a list of source citations, and a last-verified date, rather than one loose source string.

Sample data in this mockup

The five entries are drawn from the public-source research done earlier for the seed list — Buffalo Trace and Four Roses' recipe system are widely documented; Blanton's rye percentage is genuinely disputed across sources; Michter's has never disclosed a mash bill at all. That spread was picked on purpose so all four tiers show up at least once instead of everything landing in the middle.
