Beer Bible Landing Page

Today "Beer Bible" opens straight into a card grid — useful once you know what you're looking for, but it gives a new user no sense of what's actually in there. This mockup proposes a landing page in front of that grid: one screen that shows the shape of the data at a glance (how many titles, how researched they are, what styles dominate, who the top breweries are) before dropping into search or an individual beer profile.

The catalog-scale numbers below (2,539 titles, the style-mix chart) are computed from the real scripts/beer-bible-seed-data.json import file, so they reflect the store's actual SKU list. Every other number — ratings, breweries researched, the activity feed — is illustrative sample data, the same convention beer-profile-page.html uses, since the bundled seed file ships with brewery/style/abv/etc. all blank until someone researches each entry.

Design notes

A landing page, not a new data model

Every number here reads from the existing beers table (see server/db.js) — no new columns, same as beer-profile-page.html's design notes for the same reason. The style-mix chart is the one exception worth calling out: it's computed client-side from each title's text, since style itself is blank on nearly every row today. A real implementation would run that same keyword pass server-side once and cache it, falling back to the researched style column wherever it's actually filled in.

Honest about the research gap

It would be easy to make this page look more finished than the data actually is. The gap-note callout is deliberate: 2,539 titles imported, effectively zero researched, is the real current state of scripts/beer-bible-seed-data.json. Leading with that number (rather than hiding it behind cherry-picked sample cards) is what makes the "Add a Beer" CTA at the bottom feel earned instead of decorative.

The style donut is now interactive

Clicking a slice or legend row drills into that style's sub-styles (e.g. IPA → Hazy/NEIPA, West Coast, Session…) without leaving the page. It's built as clickable SVG arcs (stroke-dasharray per segment) rather than the earlier CSS conic-gradient, since a conic-gradient disc has no per-slice hit targets to attach a click handler to. Sub-style counts are illustrative — see the caveat under the drill-down itself.

ABV: two options, not a decision yet

The original bar-histogram design for ABV mix felt like the weakest chart on the page, so it's replaced here with two alternatives shown side by side for feedback rather than a single pick: a gradient spectrum band (Option A) and a beeswarm dot strip (Option B, one dot per researched beer, positioned by real ABV with a simple greedy lane-packing algorithm so close values don't overlap). Only one would ship in a real implementation.

Where the numbers come from

Real, computed from the repo's own data: 2,539 total titles, the style-mix chart's nine buckets and counts (simple keyword match against each title, run over the actual bundled seed file), the "36 recognizable breweries" figure (a fixed list of well-known national/regional brand names checked against the same titles), the package-format bars (a second keyword pass looking for "4PK"/"12PK"/"VARIETY"/etc. in each title), and the research-progress ring (currently 0 of 2,539, since brewery/style are blank on every seeded row).

Illustrative sample data: the hero's "styles researched" and "avg. Untappd rating" tiles, every beer in the Top Rated spotlight grid (real beers with real public ABV/IBU/Untappd figures, chosen to match titles already in the import file), the style donut's sub-style drill-down, both ABV mix options, the brewery bar-fill percentages, and the Recently Researched feed. None of it is live — it's there to show what the page looks like with data in it, not what's on file today.
