“Best Buy” Badge for Shelf Talkers & Display Signs

A new graphic badge marking a product as a staff-picked value, printed on the talker/sign itself rather than living only in the free-text Awards or Other Ratings field. Three visual treatments below, all built from the same fraction-of-card-width scaling every other badge in this app already uses (.card__state-badge, .card__closeout-badge in public/css/styles.css), so whichever one you pick prints correctly at every talker/sign size without new plumbing.

  • Toggle Best Buy on/off and switch Style/Corner in the panel on the left; both the Shelf Talker card and Large Display Sign previews update together.
  • Switch the sample product to Beer to see the one real wrinkle: Beer talkers already print a state-of-origin badge and a country flag in the top corners (buildRightBadgeHtml/buildCountryFlagHtml). The Seal and Starburst styles stack underneath whichever corner is already taken; the Ribbon style claims the whole corner, so it's disabled there instead of overlapping.
  • Static mockup only — not wired into the real Edit Talker form, Talker Style options, or print CSS.

Best Buy Badge

A merit designation, not a price state - kept as its own toggle rather than folded into Talker Style (Standard/Closeout/Chilled/Super Sale), since a bottle can be both on sale and a Best Buy at once.

ⓘ This corner already carries Beer's state/country badge, so Best Buy stacks underneath it here. Ribbon isn't offered for Beer for that reason. On a long 3-line beer title like this sample, the stacked badge can still crowd the description underneath it - for a US beer both corners are taken (state badge + USA flag, as shown), but for an import beer only the top-left flag applies, leaving the top-right corner free for Best Buy with no stacking needed at all.
ⓘ No corner is involved at all here, so Product Title renders exactly as it does with Best Buy off - same centering, same width, same wrap points. That also means it's the one style with nothing to work out for Beer: no stacking, no disabled Ribbon, no title reservation to double up with the state/country badges.
Why a separate toggle, not part of Talker Style

Standard/Closeout/Chilled/Super Sale describe how the price is presented and are mutually exclusive today. Best Buy describes the product - it should be combinable with any of those (a Best Buy that's also on sale is a very normal case for this store), so it reads more like a second checkbox than a fifth Talker Style option.

Design notes

  • Placement for Seal/Starburst/Ribbon reuses the same corner slot/positioning mechanic as the existing Beer-only state and country badges (.card__state-badge/.card__country-badge) and the same title-padding reservation (.card__title--badge-left/right) - just made available to Wine/Spirits too, which don't use that slot today. Inline Banner is the exception: it's laid out as a normal flow row (same idea as .card__ratings/.card__awards right below it) rather than positioned in a corner, so it never touches .card__title at all - no reservation, no wrap-point changes, and nothing to work out for Beer's existing corner badges either. The tradeoff is presence over placement: it reads as "a fact about this product," not "an eye-catching seal," closer in weight to the Ratings line than to Closeout's burst.
  • Display Signs don't have the corner conflict Shelf Talker cards do: buildLargeSignBodyHtml/buildSmallSignBodyHtml never call the state/country badge builders, so a Best Buy badge on a sign always gets a clean corner regardless of product type.
  • Sizes covered: Full and Half Size Shelf Talkers, and both Small and Large Display Signs - the same set that already carries the Closeout/Chilled badges. Quarter Size is skipped, matching how Quarter already drops every badge/ratings/description field in favor of its stripped Title/Size/Price-only layout (buildPricingHtml(talker, plain)).
  • Font-size overrides: if this ships, it'd likely want its own user-adjustable size box the way Closeout/Super Sale/Ratings already do (fRatingsFontSize etc. in app.js), rather than a fixed size - some staff will want it more/less prominent per talker.
