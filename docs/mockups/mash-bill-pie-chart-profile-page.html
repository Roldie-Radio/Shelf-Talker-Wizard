Design notes

Nothing else on the page changes

The chart replaces only the plain .grain-bar at the top of the Mash Bill block. The confidence badge/meter/note below it, the citation markers next to each heading, the sibling list, and the References & Sources section are all untouched real renderBourbonProfile output.

Siblings still swap the chart correctly

Clicking a name in "Other … entries" (right sidebar) re-renders the whole profile for that bourbon, donut included — try it from Buffalo Trace to Eagle Rare or Blanton's, both a different recipe within the same distillery family.
