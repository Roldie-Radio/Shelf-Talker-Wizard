Beer Profile Pages

Today the Beer Bible is a card grid — click a beer and it opens straight into the edit form, the same as clicking Add Beer. There's no read-focused view of an entry, the way the Bourbon Library's profile page proposal gives Bourbon. This mockup is that same idea for Beer: brewery, style, ABV/IBU, Untappd rating, and tasting notes laid out as a page, with the edit form still one click away rather than the only way in.

Unlike the Bourbon mockup, this one needs no new database columns — every field shown here (brewery, location, style, abv, ibu, untappd_rating, untappd_rating_count, description, sku, source) already exists on the beers table. It's also why there's no Mash Bill Confidence equivalent here: Beer's numbers come from a store's own Untappd export or from what a staffer typed in by hand, not from conflicting industry sources, so there's nothing to arbitrate.

Design notes

Profile page = a view, not a new editing surface

Same principle as the Bourbon mockup: every field here still lives in the existing beers row and is still edited through the same Beer Bible add/edit form (server/db.js's upsertBeer/updateBeerById). This page is a read-focused layout on top of that data — "Edit in Library" opens the existing modal pre-filled, it doesn't duplicate its fields.

The "Other … in the Library" list on the right mirrors the Bourbon profile page's sibling list, grouped by brewery instead of distillery.

Untappd rating in place of a confidence tier

Bourbon's profile page needed a confidence system because mash bill data is often disputed or simply undisclosed. Beer's untappd_rating/untappd_rating_count columns already carry their own signal of how well-established a number is — a 5-star rating from 600K+ check-ins reads very differently from one with no rating on file at all, which the star meter and count below make visible without inventing a parallel scoring system.

Sample data in this mockup

All six entries are real, well-known beers with public ABV/IBU/Untappd figures, picked so two breweries (Bell's, Founders) show up twice each — enough to exercise the "Other from this brewery" sibling list — and one entry (Guinness Draught) is shown with no description on file, to show what an unresearched entry looks like next to a fully filled-out one.
