# UI mockups

Standalone, self-contained HTML mockups for proposed UI changes &mdash; not part of
the running app, just click-through prototypes for review. Open one directly in a
browser.

- **search-tab-consolidation.html** &mdash; groups the **Search by Name**, **SKU
  Lookup**, and **Scan UPC** tabs under one new **Search** tab (as sub-tabs), cutting
  the form panel's top-level tab row from five tabs to three. Includes a Current UI /
  Proposed UI toggle so both layouts can be compared side by side; all three search
  forms are reused as-is in both, only the surrounding navigation changes.
