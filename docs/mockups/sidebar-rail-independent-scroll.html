UI fix — preview

Sidebar rail, decoupled from the header

Two changes to the app shell: the rail stops measuring itself off the header's height, and the “Shelf Talker Wizard” banner stops following you into screens that already have their own header. Scroll each frame below, and try the menu bar size buttons — both frames are live, not screenshots.

  • 1Rail spans the full window height, flush with the menu bar. Today it's position: sticky; top: 5.5rem — a number baked in to guess the header's height. The header's actual height depends on Settings → Menu Bar Size, so the guess is only ever right at one size, and the rail (Settings icon included) visibly catches out of place under the header as soon as you scroll. Moving the rail out to sit beside the header instead of below it removes the guess entirely.
  • 2The Shelf Talker Wizard header hides on the Bourbon Library and Pairing Atlas screens. Both already render their own header band (name, search, stats) the moment you switch to them — the app banner above it is a second, redundant header that just eats vertical space.
