Help

Adding a shelf talker

There are three ways to add a product, as tabs on the left:

  • Manual Entry — fill in the form yourself. Toggle Shelf Talkers vs Display Signs, and Wine / Spirits vs Beer, at the top — the fields below change to match (a Beer entry shows Brewery/Style/ABV/IBU instead of Ratings and Vintage, for example). Vintage (Wine / Spirits only) prints centered on its own line right under the product title, in the same style as the description. For Wine / Spirits, the Find Tasting Notes button under Description searches the web using the Product Title (and Vintage, if set) and fills the field in for you — see "Finding tasting notes automatically" below. Awards or Other Ratings (Wine / Spirits only) is free-text below the numeric Ratings list, for medals or other honors that don't fit the reviewer/score format — it prints in the same bold style as Ratings, in the color you pick with the swatch next to the field.
  • Import from Website — paste a URL and let the app fill in what it can. See "Importing from a website" below.
  • Bulk CSV Import — paste a CSV to add many wine/spirits shelf talkers at once. Columns: title,description,size,price,salePrice,theme,type. Only title and price are required; type can be standard, closeout, supersale, or chilled.

Talker sizes and styles

Talker Size (Full/Half/Quarter) changes how many print per sheet — a Quarter Size talker is a quarter the paper of a Full Size one. Talker Style adds a badge or callout: Closeout for a clearance badge, Super Sale (Wine / Spirits only — the store doesn't run Super Sales on beer) to replace the price with a stylized callout, or Also Available Chilled for a small blue note.

Finding tasting notes automatically

On the Manual Entry form, Wine / Spirits entries have a Find Tasting Notes button (marked Beta — it's new, so double-check what it finds) under the Description field. Click it (with a Product Title already filled in) to open a dialog that searches using the title and Vintage, if set — no URL to paste. The Source dropdown picks which site to search — currently Wine.com and Vivino: Any source (the default) tries each in order and stops at the first that finds something; picking a specific site searches only that one. Whatever it finds shows in an editable preview box — tweak it if you'd like, then click Use This Description to drop it into the form (it'll ask before overwriting anything already typed), or Cancel to close without changing anything. If a site blocks the request outright, it automatically retries once with different request headers before giving up (same as the Untappd import below); if it's still blocked, or the site has nothing for that product, the dialog shows why and you can try a different source or type the description in by hand.

Importing from a website

On the Import from Website tab, switch between Wine / Spirits and Beer to match what you're importing:

  • Wine / Spirits — paste a product page URL from the store's website. Pulls the title, description, and price.
  • Beer — paste a beer's Untappd page URL (untappd.com/b/...). Pulls the brewery, location, style, ABV, IBU, rating, and description — not price or size, since Untappd doesn't sell anything, so add those two yourself.

Either way, review the fields before adding to the queue — a field the importer can't find just comes back blank. If a beer import reports Untappd blocked the request, wait a bit and try again, or enter the details by hand.

The queue

Everything you've added sits in the Queue panel on the right, and is saved automatically in the browser so it survives closing the app. Click the ⋮ menu on any item to Edit, Copy, Delete, or Move Up/Move Down it — queue order is print order, so moving an item changes where it lands on the printed sheet.

Preview

The Live Preview panel shows either the single talker you're currently editing (Current Talker) or a scaled-down full printed sheet with everything queued (Full Page), with Prev/Next to page through multiple sheets. Both are laid out at the exact size they'll print at, just shrunk to fit your screen — what you see here is what comes out of the printer.

Printing

Click Print Sheet(s)… to open the Print Preview, which shows every sheet that will print and how full each one is. Auto-arrange (Beta) can pack different talker/sign sizes onto shared sheets to save paper — off by default since it's newer. Click Print Now to open the system print dialog; choose "Save as PDF" there instead of a printer if you just want a file.

Dark mode

The Dark/Light button in the top right switches the app's own colors. It never changes the shelf talkers or signs themselves — those always preview and print in their normal colors on white paper, regardless of which theme the app is in.

Saving and opening a queue file

Use the File menu's Save Queue and Open Queue… to back up the current queue to a file, or load one on another PC. This is separate from the automatic save mentioned above — it's for moving a queue between computers or keeping an archive of a batch.
