Help

Adding a shelf talker

There are three tabs on the left for adding a product. Every one of them opens with the same two dropdowns: Type (Shelf Talker, Small Display, or Large Display) and Product Type (Wine / Spirits, Bourbon, or Beer) — the fields below change to match (a Beer entry shows Brewery/Style/ABV/IBU instead of Ratings and Vintage, for example, and a Bourbon entry adds Mash Bill, Nose/Palate/Finish, and Store Pick on top of everything Wine / Spirits gets). Both are shared across all three tabs: change either one on any tab and it stays set that way when you switch tabs.

  • Edit Talker — fill in the form yourself. Vintage (Wine / Spirits only) prints centered on its own line right under the product title, in the same style as the description. For Wine / Spirits, the Find Tasting Notes button under Description searches the web using the Product Title (and Vintage, if set) and fills the field in for you — see "Finding tasting notes automatically" below. Awards or Other Ratings (Wine / Spirits only) is free-text below the numeric Ratings list, for medals or other honors that don't fit the reviewer/score format — it prints in the same bold style as Ratings, in the color you pick with the swatch next to the field. Case Price (Large Display only, optional) prints bottom-right in the same bold style as Regular Price — Shelf Talkers and Small Display Signs have no room for it, so the field is hidden for those.
  • Website — paste a URL and let the app fill in what it can. See "Importing from a website" below.
  • Search — type a name, SKU, or UPC into one box and look the product up instead of typing everything by hand; it figures out which of the three you meant. See "Searching, by name, SKU, or UPC" below.

Talker sizes and styles

Talker Size (Full/Half/Quarter, Edit Talker only, Shelf Talker Type) changes how many print per sheet — a Quarter Size talker is a quarter the paper of a Full Size one. Talker Style adds a badge or callout: Closeout for a clearance badge, Super Sale (Wine / Spirits only — the store doesn't run Super Sales on beer) to replace the price with a stylized callout, or Also Available Chilled for a small blue note.

Finding tasting notes automatically

Turn on Find Tasting Notes under Settings → Experimental Features to add a Find Tasting Notes button (marked Experimental — it's new, so double-check what it finds) under the Description field for Wine / Spirits and Bourbon entries. Click it (with a Product Title already filled in) to open a dialog that searches using the title and Vintage, if set — no URL to paste. The Source dropdown picks which site to search — currently Wine.com and Vivino: Any source (the default) tries each in order and stops at the first that finds something; picking a specific site searches only that one. Whatever it finds shows in an editable preview box — tweak it if you'd like, then click Use This Description to drop it into the form (it'll ask before overwriting anything already typed), or Cancel to close without changing anything. If a site blocks the request outright, it automatically retries once with different request headers before giving up (same as the Untappd import below); if it's still blocked, or the site has nothing for that product, the dialog shows why and you can try a different source or type the description in by hand.

Importing from a website

On the Website tab, set Product Type above to match what you're importing:

  • Wine / Spirits — paste a product page URL from the store's website. Pulls the title, description, and price.
  • Beer — paste a beer's Untappd page URL (untappd.com/b/...). Pulls the brewery, location, style, ABV, IBU, rating, and description — not price or size, since Untappd doesn't sell anything, so add those two yourself.

Either way, review the fields, then click Add to Queue — a field the importer can't find just comes back blank. Fetching keeps you on the Website tab and keeps whatever Type/Talker Size you had selected, so you can paste another URL and repeat without re-picking anything. If a beer import reports Untappd blocked the request, wait a bit and try again, or enter the details by hand.

Searching, by name, SKU, or UPC

The Search tab covers three lookup methods — Search by Name, SKU Lookup, and Scan UPC — behind a single search box under Type/Product Type: type a product name, a store SKU, or scan/type a UPC, and it detects which one you meant and switches automatically. All three share the Type and Product Type dropdowns above them instead of asking again per method.

Searching by product name

The Search by Name method looks products up by title instead of a SKU or UPC — useful when you know roughly what you're looking for but not its number. Like Scan UPC below, the matching itself reads the same product file WinePOS exports on this PC and never goes out to the internet, so it needs that export set up first (the same Advanced → Export File Settings… one-time setup). Start typing a product name and a list of the closest matches appears underneath the box, ranked so the best match is first — use the mouse, or ↑/↓ and Enter, to pick one. Picking a result fills in the title, size, vintage, and price right away, same as the other lookup methods. For Wine / Spirits, picking it also checks liquoroutletwinecellars.com in the background for a fresher sale price and description — the export file's own Description column tends to be blank or a short internal note, same reason Scan UPC below does the same store check; the status line shows "Checking the store site..." while that runs. For a Beer result, picking it instead kicks off a quick Untappd search using that title — the same lookup SKU Lookup and Scan UPC already run for beer — and fills in the brewery, style, ABV, IBU, and rating a WinePOS export doesn't carry; the status line shows "Searching Untappd..." while that runs, and says so if Untappd has no match, same as those two methods. Review the fields, then click Add to Queue. If nothing close enough turns up, the list says so — add the item manually instead.

For a Beer result whose export row also has a pack price (a separate column beyond the per-unit price — check with whoever maintains the WinePOS export if this is missing), the selected-product summary adds a Unit / Pack choice, defaulting to Pack, since beer here is mostly shelved and shopped by the pack or case. Click Unit instead if the talker is meant for singles — the form's price field updates immediately either way. Picking Pack clears the Sale Price field too, since the export only has a per-unit sale price; add a pack sale price by hand if the pack itself is on sale.

Looking up a product by SKU

On the SKU Lookup method, set Product Type above to match the product, then type the store's SKU number into the Search box and press Enter. It searches liquoroutletwinecellars.com for that SKU, opens the matching product page, and pulls the title, size, and pricing straight from it. For Beer, it also searches Untappd using the title it just found and fills in the description, brewery, style, ABV, IBU, and rating from there — the store page's own description is only used if that Untappd search doesn't turn up a match. Review the fields before adding to the queue, same as any other import. If the store site blocks the lookup, use Site blocking the lookup? Paste the product page's HTML instead: search the SKU yourself on the store's website, open the matching product page, copy its HTML source, and paste it in — this works even when the site blocks the app's own request, since your browser already got past it.

Scanning a UPC

The Scan UPC method looks products up by the manufacturer UPC printed on the bottle — a different number from the store's own SKU that SKU Lookup searches the website for. The core lookup itself never goes out to the internet: it reads a product file that WinePOS exports locally on this PC. Scan or type into the Search box at the top of the tab — once it recognizes a UPC it presses Enter to trigger the lookup itself, same as a USB/Bluetooth scanner's own trailing Enter keystroke, so nothing else needs clicking. The first time, use the desktop app's Advanced → Export File Settings… menu and point it at the file WinePOS writes (ask WinePOS support how to set up that export if it isn't running yet); after that it's saved on this PC and re-read automatically whenever the file changes. If a scanned UPC isn't in the file, add that item manually instead.

Once an item is found in the file, Wine / Spirits pulls a fresher description from liquoroutletwinecellars.com using the export's own store SKU — the same site SKU Lookup already reads one from. Beer instead looks itself up on that same site (title, size, and pricing), then fills in the brewery, location, style, ABV, IBU, and rating from Untappd using that store-listed name — the exact same two-step lookup SKU Lookup's own Beer path runs, which finds far more on Untappd than searching with the export file's own (often abbreviated) title would. Either of those steps failing just leaves the export file's own value in place for that field, with a note explaining why.

If the scanned row's own export data also has a pack price (a separate column beyond the per-unit price — check with whoever maintains the WinePOS export if this is missing), a Unit / Pack choice appears under the status line, same control and same Pack default as Search by Name's own (see above) — beer here is mostly shelved and shopped by the pack or case. Click Unit instead if the talker is meant for singles; the price updates immediately either way, and picking Pack clears the Sale Price field too, since the export only has a per-unit sale price. A scan with a Unit/Pack choice to make always stops for a manual Add to Queue click, so a pick you never saw doesn't get queued out from under you.

A scan that comes back completely clean, with no Unit/Pack choice to make, is added to the queue automatically — there's no "Add to Queue" click needed, so you can walk the aisle and keep scanning one bottle after another, with the Search box clearing and staying focused for the next scan. If anything above couldn't be filled in (a store SKU the site didn't recognize, a beer Untappd has no match for, and so on), the scan stops short of the queue instead: the fields stay filled in with whatever did resolve, the status line explains what didn't, and you decide whether to click Add to Queue as-is or fix it on Edit Talker first. The same holds if a scan is missing something the queue always requires, like a price.

The queue

Everything you've added sits in the Queue panel on the right, and is saved automatically in the browser so it survives closing the app. Click the ⋮ menu on any item to Edit, Copy, Delete, or Move Up/Move Down it — queue order is print order, so moving an item changes where it lands on the printed sheet.

Preview

The Live Preview panel shows either the single talker you're currently editing (Current Talker) or every sheet the queue will print, stacked in a scrollable list (Full Page). Both are laid out at the exact size they'll print at, just shrunk to fit your screen — what you see here is what comes out of the printer. On Full Page, click any talker or sign on the sheet to jump straight into editing it — the same as choosing Edit from its Queue row's ⋮ menu, just without having to find the matching row first.

Printing

Full Page doubles as the print preview, showing how full each sheet is, with an Auto-arrange toggle above it that can pack different talker/sign sizes onto shared sheets to save paper — off by default, so you can compare it against the grouped sheets before relying on it. Click Print Sheet(s)… in the top bar to jump straight to Full Page; once you're looking at it, that same button becomes Print Now and opens the system print dialog. Choose "Save as PDF" there instead of a printer if you just want a file.

Print History

The History button in the top bar opens a permanent, searchable record of every talker that's actually been printed — unlike the Queue, items here never disappear on their own. Search by title or SKU, then click Reprint on any result to add a fresh copy back into the current Queue (it doesn't print immediately — review it first, same as anything else in the Queue). Delete removes a mistaken entry from History only; it has no effect on the Queue.

Dark mode

The Dark/Light button in the top right switches the app's own colors. It never changes the shelf talkers or signs themselves — those always preview and print in their normal colors on white paper, regardless of which theme the app is in.

Saving and opening a queue file

Use the File menu's Save Queue and Open Queue… to back up the current queue to a file, or load one on another PC. This is separate from the automatic save mentioned above — it's for moving a queue between computers or keeping an archive of a batch.

Export File Settings

Point this at the product file WinePOS exports on this PC (CSV or tab-delimited, with a UPC/Barcode column and a price and description/title column). It's re-read automatically whenever the file changes — no need to restart the app after WinePOS updates it. Only the PC WinePOS actually writes that file on (marked Server PC in the Advanced menu) needs this — every other register should use auto-sync below instead.

Auto-sync — instead of a path above, automatically pull the export file over the network from whichever PC is currently marked Server PC (Advanced → Server PC on that PC), refreshed about every 30 seconds. Turn this on for every register except the Server PC itself.

Import Beer Bible from Export File

Point this at a beer product export (CSV/TSV, or an Excel .xlsx/.xlsm workbook - the same kind of file WinePOS exports) and every row's title is looked up on Untappd, same as Search by Name already does, and saved straight into this PC's own Beer Bible. A row Untappd can't confidently match is skipped, never guessed at. This can take a while for a large file (roughly half a second per row) - it keeps running even if this dialog is closed, and skips a row whose SKU is already saved, so it's safe to close and reopen, or cancel and resume later.

Export CSV

Downloads every beer in the Beer Bible as a CSV file - for backing the library up or opening it in a spreadsheet.

Import CSV

The round-trip counterpart to Export CSV above - reads a CSV shaped like that one's own output (or a subset of its columns) back in, upserting each row the same way Add Beer/Edit would (SKU first, title second; a blank cell never overwrites an already-fuller field). Not the same thing as Advanced → Import Beer Bible from Export File…: that one runs a live Untappd search per row, this one expects every field already filled in and just merges it in, synchronously, no network calls.
